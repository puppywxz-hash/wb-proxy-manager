WorkBuddy Proxy 管理面板

把已登录的 WorkBuddy 桌面客户端模型, 以 OpenAI / Anthropic 兼容接口暴露给 Codex / ZCode / DSH 等客户端。

DSH / OpenAI 兼容客户端 接入配置

最常用: Codex 国内版 (8401) 同时提供 /v1/chat/completions 标准 OpenAI 接口, DSH 里直接填下面 URL 即可。
API Key: 代理默认不校验 Bearer, 填 sk-any 或任意字符串即可; 若你设了 WB_PROXY_TOKEN 则填那个值。
若 DSH 只认 Anthropic 协议, 改用 ZCode 国内版 (8400) 的 URL。
